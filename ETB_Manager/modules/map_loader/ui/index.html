OUTILS CARTOGRAPHIQUES

Gestionnaire de cartes

Les cartes de jeu sont affichées dans leurs modules respectifs. Les options communes sont définies dans la configuration générale ; chaque carte peut les remplacer avec sa configuration locale.

Configuration générale

Fichier : modules/map_loader/public/map-defaults.json

Définit les catégories visibles par défaut et les comportements communs aux cartes.

Configurations locales

Chaque module de carte possède son propre fichier public/map.config.json. Les valeurs locales sont prioritaires sur les valeurs générales.

Importation de cartes

Le chargeur de fichiers JSON vers HTML sera ajouté ici, afin de séparer la préparation des cartes de leur affichage en jeu.
