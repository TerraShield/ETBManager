# Module Level 0

Ce module expose la position et l'orientation depuis l'état partagé du lecteur mémoire.

Pour retrouver l'ancienne carte live, copie `level0_live_map.html` directement dans ce dossier ou dans `public/`. Son appel historique à `/pos` est conservé. En l'absence de ce HTML, l'aperçu statique `public/Level0_map_v0.png` reste disponible.
